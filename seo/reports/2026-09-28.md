### 6. Coverage fell 81% → 58%, and the cause is event names

The unmatched list is almost entirely events searched by name: "fluff fest" and
nine variants (~80 impressions), "open streets allston" and three variants (58),
"bu sustainability festival" (38, at position 3.2). Every `events-programs`
pattern needs a bike/walk word or a town *in front of* the event word, and
people don't type event names that way.

This is the same lesson `roams-trails` taught on 2026-09-21, with a twist. That
cluster was fitted to a sample, and the fix was to regenerate it from the full
inventory. Event inventory turns over weekly, so a name list would decay even
faster. **Item 1** adds the generic *shapes* of an event name (fest/festival,
open streets, "<year> schedule") and patches three Roam misses. Replayed:
coverage **58% → 94%**, non-brand trigger **unchanged at 455**, so this only
reclassifies traffic and adds none.
